# Sicarus — Deployable Satellite Structure (Design & Simulation)

## What this is

Sicarus is a satellite-structure design study. It asks what happens when debris punctures a deployable structure such as a solar sail or antenna reflector, and whether the structure can be designed to keep working afterwards.

The project is a design and computer simulation. Nothing has been built or tested in hardware. The video is a rendered demonstration of the simulated behaviour, produced from the simulation code.

## Scope and status

- Stage: design and simulation only.
- Intellectual property: an Indian provisional patent application has been filed for the invention (application no. 202621134864, patent pending). Technical details beyond this summary are withheld while the application is pending.
- Development: the 3D models and simulation code were written with AI assistance (Claude) to my specifications. The concept, the design decisions and the technical direction are my own.
